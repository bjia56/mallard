# mallard

A Claude Code plugin with one skill, `mallard`: a patient, duck-themed guide that explains what is going on in a diff, commit, branch, or PR, and shows you how to review it.

## Install

```
/plugin install mallard --marketplace bjia56/mallard
```

Then ask things like "explain PR 123" or "walk me through this diff". The skill is `mallard:mallard`.

## Develop

```
claude --plugin-dir .
```
